# Amazon Sales Dashboard — Excel

## 📊 Project Overview

This is an Excel-based Amazon Sales Dashboard created as a learning project while developing my data analytics skills.

The project uses an Amazon sales dataset and demonstrates how Microsoft Excel can be used to clean, organize, analyze, and visualize data through an interactive dashboard.

The dashboard was developed with the help of a YouTube tutorial, which I used as a learning reference to practice Excel dashboard development and understand how different Excel features work together.

## 🎯 Project Objectives

* Practice working with real-world sales data
* Understand data cleaning and preparation
* Create meaningful KPIs
* Analyze sales and order-related information
* Analyze product and category performance
* Explore customer ratings
* Build interactive visualizations
* Develop an Excel dashboard

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Excel Slicers
* KPI Creation
* Data Visualization
* Dashboard Design
* Basic Business Analysis

## 📈 Dashboard

The dashboard provides an interactive view of the available sales data, including:

* Sales performance
* Orders
* Products
* Categories
* Customer ratings
* Key performance indicators
* Interactive filtering using slicers

## 🔄 Project Workflow

```text
Raw Data
   ↓

   ↓

   ↓

   ↓

   ↓

```
